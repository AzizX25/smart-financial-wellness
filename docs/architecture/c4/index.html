Déploiement · Environnement local

Instances Compose actuelles et services sur le poste ; ports hôte configurables.

Télécharger le SVG · Ouvrir le SVG seul

  • Les connexions navigateur vers le backend utilisent une URL publique ; les noms de service Compose sont réservés aux appels entre conteneurs.
  • Les ports sont les valeurs de Compose, configurables par environnement. :8082 est le port backend observé pendant cette session.
  • Les deux volumes PostgreSQL sont distincts. Les healthchecks et depends_on n'impliquent pas une disponibilité garantie des fonctionnalités IA.
